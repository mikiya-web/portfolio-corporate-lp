# Speed Up Design Studio

架空のWeb制作会社を想定したランディングページです。
サービス内容・制作実績・会社紹介・FAQ・お問い合わせを1ページにまとめています。

## 公開URL

https://mikiya-web.github.io/portfolio-corporate-lp/

## 制作目的

HTML・CSSによるレスポンシブなレイアウトと、
JavaScriptによる画面操作の実装を学ぶために制作しました。

## 使用技術

- HTML
- CSS
- JavaScript
- Font Awesome（CDN）
- Git / GitHub
- GitHub Pages

## 主な実装

- PC用ナビゲーションとスマホ用ハンバーガーメニュー
- ページ内リンクによる各セクションへの移動
- Intersection Observerを使ったスクロール時の表示
- 制作実績のスライダー
- サムネイルによる制作実績の切り替え
- スマホでの手動スクロールと現在位置表示の連動
- FAQのアコーディオン
- お問い合わせフォームの必須入力・メール形式チェック
- 画面幅に応じたレスポンシブ表示

## 工夫した点

### 制作実績をデータとして管理

制作実績の画像や文章をJavaScriptの配列で管理し、
そのデータから表示要素を生成しています。

現在の表示位置をcurrentIndexで管理し、
前後ボタン・サムネイル・ページ番号を連動させています。

### PCとスマホに合わせたスライダー

PC用とスマホ用の表示を用意しています。
スマホでは手動スクロール後にも表示位置を確認し、
ページ番号と前後ボタンの状態を更新しています。

### FAQの開閉状態を管理

質問を押すと回答を開閉し、ほかの回答を閉じる構成にしています。
開閉状態に合わせてaria-expandedも更新しています。

### フォームの入力チェック

必須項目の空欄とメールアドレスの形式を確認し、
各入力欄の下にエラーメッセージを表示します。

ラベルと入力欄を紐付け、
ラベルを押して入力欄を選択できるようにしています。

## デモとしての範囲

- このサイトに登場する会社・サービス・制作事例は架空です。
- 制作事例内の成果数値は説明用のサンプルで、実際の実績ではありません。
- お問い合わせフォームは入力チェックのデモです。
- 入力内容の送信・サーバー保存・メール送信は行いません。
- Recruit・Entryのリンク先は、デモの案内ページです。

## ファイル構成

- index.html：メインページ
- style.css：メインページの装飾・レスポンシブ対応
- script.js：メニュー・スライダー・FAQ・フォームなどの処理
- reset.css：ブラウザの標準スタイルの調整
- dummy.html：採用・エントリーのデモ案内ページ
- dummy.css：デモ案内ページの装飾
- img/：サイト内の画像
- README.md：制作物の説明

## ローカルでの確認方法

リポジトリをクローンし、index.htmlをブラウザで開いてください。

パッケージのインストールやビルドは不要です。
Font AwesomeはCDNから読み込むため、アイコン表示にはインターネット接続が必要です。
